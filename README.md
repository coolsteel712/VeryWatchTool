# VeryWatchTool

**VeryWatchTool** is a free, open-source watch face editor for the **TOOBUR IDW20**, **Yoever IDW18**, and many other VeryFit-compatible smartwatches.

Create, edit, preview, and compile custom watch faces without relying on proprietary software.

## Beta Status

VeryWatchTool is currently in **Beta v0.3.0**. While most features are functional, you may encounter bugs, incomplete features, or unexpected behavior. Feedback and bug reports are welcome.

## Compiling Watch Faces

CloudDialMake can compile watch faces directly. If you need support for additional color formats or batch compilation, CloudDialMake is in the VeryWatchTool root folder.

## Sideloading Watch Faces

Instead of replacing files inside the hidden directories of the VeryFit app, **VeryLoad** can sideload custom watch faces directly to supported devices using a reverse-engineered VeryFit watch face protocol.

Repository:

https://github.com/coolsteel712/VeryLoad/

## Supported Models

Currently supported:

* Octandra IDW13
* Yoever IDW18
* TOOBUR IDW20

Planned support may include additional devices such as:

* TOOBUR IDW17
* IDO ID Sport03
* Other VeryFit-compatible models
